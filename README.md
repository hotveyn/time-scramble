# ⏳ Time Scramble

**Stop watching the clock. Start doing the work.**

A macOS menu-bar app that sets the system clock to a random time every few minutes,
so you lose track of elapsed time and stay in the flow.

## Features

- 🎲 **Random time** within the current day, every 1–120 minutes
- ⏸️ **Pause and resume** without losing settings
- 🔄 **Real time restored** on stop, and after a crash on next launch
- 🫥 **Menu bar only**: no window to remind you of the time

## Build

1. Open `time-scramble.xcodeproj` in Xcode 15+
2. Press <kbd>⌘</kbd> <kbd>R</kbd>

> [!NOTE]
> Not on the Mac App Store: Apple does not allow apps that change the system clock.
